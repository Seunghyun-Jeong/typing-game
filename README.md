# 타자 연습 게임

화면에 나온 문자를 제한 시간 안에 입력하는 타자 게임입니다.
수업 예제(`exam4.html`)의 문제점을 고치고 파일을 분리해 다시 만들었습니다.

## 실행

```bash
python3 -m http.server 5500
```

브라우저에서 `http://localhost:5500` 으로 접속합니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 스타일 |
| `script.js` | 게임 로직 |

## 원본에서 고친 것

**헷갈리는 글자 제거** — `I`/`l`, `O`/`0`, `1` 은 화면에서 구분이 안 돼
실력이 아니라 운으로 점수가 갈렸습니다. 출제 목록에서 뺐습니다.

**같은 글자 연속 출제 방지** — 눌렀는지 안 눌렀는지 알 수 없는 상황이 없어집니다.

**한글 입력 상태 안내** — 한영 전환을 깜빡하면 원본은 계속 감점만 됐습니다.
이제 감점 대신 "한영 키를 눌러주세요"라고 알려줍니다.

**특수키 감점 제거** — 원본은 `Shift`, `CapsLock` 만 걸렀습니다.
`Ctrl`, `Alt`, `Tab`, 방향키, `F5` 를 눌러도 오답으로 처리돼 점수가 깎였습니다.

**Space/Enter 로 버튼 재실행 차단** — Start 를 클릭하면 버튼에 포커스가 남아,
게임 중 스페이스나 엔터를 누르면 버튼이 다시 눌렸습니다.

**시계 기반 타이머** — `setInterval` 호출 횟수를 세면 탭이 백그라운드로 갈 때
시간이 밀립니다. 실제 시각으로 남은 시간을 계산합니다.

**점수 하한선** — 계속 틀리면 점수가 끝없이 내려가 의욕이 꺾입니다. 0 에서 멈춥니다.

**결과를 타이머 자리에 표시하지 않음** — 원본은 "남은 시간" 자리에 최종 점수를
덮어썼습니다. 결과 영역을 따로 두었습니다.

**모바일 지원** — `keydown` 만으로는 가상 키보드 입력을 못 받는 기기가 있어,
숨은 입력칸의 `input` 이벤트로 받습니다.

## 추가한 것

- 남은 시간 progress bar (25% 이하에서 빨강)
- 정답/오답 즉시 피드백 (색 + 흔들림)
- 연속 정답(콤보) 카운트
- 최고 점수 저장 (localStorage)
- 반응형 레이아웃, 키보드 포커스 표시, `prefers-reduced-motion` 대응
